# Site Security Maintenance - Dependabot
Follow these steps to evaluate and remediate open security issues.

1. Open a new task with Bob and have the DSCE repo open.
2. Select the IBM Bob mode called "Security & Vulnerability Scanner"
3. Paste url for dependabot security report.  E.g. like [IBM OSPO #231](https://github.com/IBM/dsce-sample-apps/issues/231)
3. Tell Bob to read the security report then evaluate and remediate open security issues.
4. Check-in Bob's changes
5. Go to the Security and Quality tab in the DSCE repo. Click on `Dependabot > Vulnerabilities` then `Refresh Dependabot Alerts].
