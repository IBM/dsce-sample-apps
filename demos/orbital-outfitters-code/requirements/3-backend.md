# Requirements: Backend API

## 1. Overview

Express.js REST API for the Orbital Suppliers retail website.

- **Runtime:** Node.js (ESM, `"type": "module"` in `package.json`)
- **Framework:** Express 4.x
- **Auth:** Stateless JWT — tokens are signed with `JWT_SECRET`, verified per-request by middleware; no server-side session store
- **Database:** PostgreSQL via `pg` connection pool; all queries scoped to schema `DB_SCHEMA`
- **Vector search:** OpenSearch (`@opensearch-project/opensearch@^2`) with k-NN index; embeddings generated by `@xenova/transformers` (`Xenova/all-MiniLM-L6-v2`, 384 dimensions)
- **Agent:** watsonx Orchestrate REST API called via `axios`
- **Docs:** Swagger YAML at `backend/docs/swagger.yaml`, served at `BACKEND_SWAGGER_URL`
- **Entry point:** `backend/index.js`
- **Port:** `BACKEND_PORT` (default `3001`)

## 5. Middleware

### `backend/middleware/auth.js` — `requireAuth`

Exported as a default Express middleware function. Applied to all JWT-protected routes.

**Logic:**

1. Read the `Authorization` header. If absent or not in the form `Bearer <token>`, respond `401 { error: "No token provided" }`.
2. Call `jwt.verify(token, process.env.JWT_SECRET)`. If verification throws (`JsonWebTokenError`, `TokenExpiredError`), respond `401 { error: "Invalid or expired token" }`.
3. On success, attach the decoded payload to `req.user` and call `next()`.

**JWT payload shape** (set at login):

```json
{
  "user_id": 42,
  "email": "user@example.com",
  "username": "jsmith"
}
```

Token expiry: `"24h"`.

## 6. Database

### `backend/db/pool.js`

```javascript
import pg from 'pg';
import 'dotenv/config';

const { Pool } = pg;

const pool = new Pool({
  host:     process.env.DB_HOST,
  port:     Number(process.env.DB_PORT),
  database: process.env.DB_NAME,
  user:     process.env.DB_USER,
  password: process.env.DB_PASSWORD,
  ssl:      process.env.DB_SSL === 'true' ? { rejectUnauthorized: false } : false,
});

// Schema-qualified query helper — all queries must use this
export async function query(text, params) {
  const client = await pool.connect();
  try {
    await client.query(`SET search_path TO ${process.env.DB_SCHEMA}`);
    return await client.query(text, params);
  } finally {
    client.release();
  }
}

export default pool;
```

- Every query goes through the `query()` helper to ensure `search_path` is set.
- Use parameterised queries (`$1`, `$2`, …) for all user-supplied values — no string interpolation.

## 7. Endpoint Specifications

### 7.1 Auth Endpoints

---

#### `POST /auth/login`

**Auth:** None

**Request body:**
```json
{ "login": "user@example.com", "password": "password" }
```
`login` may be either `email` or `username`.

**SQL:**
```sql
SELECT user_id, first_name, last_name, email, username, area_code, phone,
       address_1, address_2, city, state, zip_code,
       email_opt_in, created_at, password_hash
FROM   users
WHERE  email = LOWER(TRIM($1))
   OR  username = $1
LIMIT  1;
```

**Password verification:**
```javascript
import crypto from 'crypto';
const expected = crypto
  .createHmac('sha256', process.env.PASSWORD_HASH_SECRET)
  .update(`${email_lower}_${process.env.USER_PASSWORD ?? password}`)
  .digest('hex');
// compare expected === row.password_hash
```

> The dataset was generated with `hmac(PASSWORD_HASH_SECRET, email.lower() + "_" + USER_PASSWORD)`. Verify against `password_hash` stored in the DB. The plain-text password field in the request body is only used to derive the HMAC — it is never stored.

**Correct verification pattern:**
```javascript
const email_lower = login.includes('@') ? login.toLowerCase().trim() : null;
const text_to_hash = (email_lower ?? login) + '_' + password;
const digest = crypto.createHmac('sha256', process.env.PASSWORD_HASH_SECRET)
  .update(text_to_hash).digest('hex');
// Match digest against row.password_hash
```

**Success response `200`:**
```json
{
  "token": "<jwt>",
  "user": {
    "user_id": 42,
    "first_name": "Jane",
    "last_name": "Smith",
    "email": "jane@example.com",
    "username": "jsmith",
    "area_code": "415",
    "phone": "555-1234",
    "address_1": "123 Main St",
    "address_2": null,
    "city": "San Francisco",
    "state": "CA",
    "zip_code": "94105",
    "email_opt_in": false,
    "created_at": "2024-01-01T00:00:00.000Z"
  }
}
```

**Errors:** `400` missing fields · `401` invalid credentials · `500` DB error

### 7.2 Product Endpoints

---

#### `GET /products`

**Auth:** None

**Query params:**

| Param | Type | Default | Description |
|---|---|---|---|
| `search` | string | — | Filter by `name ILIKE '%search%'` or `description ILIKE '%search%'` |
| `category` | string | — | Filter by `category = $n` (exact, case-sensitive) |
| `page` | integer | `1` | Offset pagination |
| `limit` | integer | `20` | Max 100 |

**SQL (base):**
```sql
SELECT product_id, name AS product_name, description AS product_description,
       image_url AS product_image_url, category, price, currency,
       in_stock, inventory_quantity, shipping_days,
       width_inches, height_inches, depth_inches, weight_lbs,
       feature1, feature2, feature3, feature4
FROM   products
WHERE  is_active = true
  [AND (name ILIKE $n OR description ILIKE $n)]   -- if ?search=
  [AND category = $n]                              -- if ?category=
ORDER  BY name
LIMIT  $n OFFSET $n;
```

Also run a `COUNT(*)` with the same `WHERE` clause and return it in the envelope.

**Success response `200`:**
```json
{
  "products": [ { "product_id": "sprocket_001", "product_name": "...", ... } ],
  "total": 47,
  "page": 1,
  "limit": 20
}
```

**Errors:** `400` invalid page/limit · `500`

---

#### `GET /products/:id`

**Auth:** None

**SQL:**
```sql
SELECT p.product_id, p.name AS product_name, p.description AS product_description,
       p.image_url AS product_image_url, p.category, p.price, p.currency,
       p.in_stock, p.inventory_quantity, p.shipping_days,
       p.width_inches, p.height_inches, p.depth_inches, p.weight_lbs,
       p.feature1, p.feature2, p.feature3, p.feature4,
       COALESCE(
         json_agg(
           json_build_object(
             'id', r.id,
             'review', r.review,
             'score', r.score,
             'reviewer_initials', r.reviewer_initials,
             'created_at', r.created_at
           ) ORDER BY r.created_at DESC
         ) FILTER (WHERE r.id IS NOT NULL),
         '[]'
       ) AS reviews
FROM   products p
LEFT   JOIN product_reviews r ON r.product_id = p.product_id
WHERE  p.product_id = $1
GROUP  BY p.product_id;
```

**Success response `200`:**
```json
{
  "product_id": "sprocket_001",
  "product_name": "...",
  "reviews": [
    { "id": 1, "review": "Great product", "score": 5, "reviewer_initials": "JS", "created_at": "..." }
  ]
}
```

**Errors:** `404` product not found · `500`

### 7.3 Cart Endpoints

All cart endpoints require `requireAuth`.

---

#### `GET /cart`

**Logic:** Look up the active cart for `req.user.user_id`. If none exists, `INSERT` an empty cart with `status = 'active'` and return it with an empty `items[]`.

**SQL — fetch cart with items:**
```sql
SELECT c.cart_id, c.status, c.created_at, c.updated_at,
       ci.cart_item_id, ci.product_id, ci.quantity, ci.unit_price, ci.added_at,
       p.name AS product_name, p.image_url AS product_image_url, p.price
FROM   cart c
LEFT   JOIN cart_items ci  ON ci.cart_id  = c.cart_id
LEFT   JOIN products   p   ON p.product_id = ci.product_id
WHERE  c.user_id = $1 AND c.status = 'active';
```

**Success response `200`:**
```json
{
  "cart_id": 7,
  "status": "active",
  "items": [
    {
      "cart_item_id": 3,
      "product_id": "sprocket_012",
      "product_name": "Space Wrench",
      "product_image_url": "https://...",
      "quantity": 2,
      "unit_price": "29.99",
      "line_total": "59.98"
    }
  ],
  "subtotal": "59.98",
  "item_count": 1
}
```

`line_total` = `unit_price × quantity` (computed in JS). `subtotal` = sum of all `line_total` values.

**Errors:** `401` · `500`

---

#### `POST /cart/items`

**Request body:**
```json
{ "product_id": "sprocket_012", "quantity": 2 }
```

**Logic:**
1. Get or create the active cart for `req.user.user_id`.
2. Look up `price` from `products` for `product_id`.
3. If the product already exists in `cart_items` for this cart, `UPDATE quantity = quantity + $quantity`.
4. Otherwise `INSERT` a new `cart_items` row with `unit_price` set to the product's current `price`.
5. Update `cart.updated_at = NOW()`.

**Success response `201`:** Full cart object (same shape as `GET /cart`).

**Errors:** `400` missing fields or quantity < 1 · `404` product not found or inactive · `401` · `500`

---

#### `PUT /cart/items/:cart_item_id`

**Request body:**
```json
{ "quantity": 3 }
```

**Logic:**
1. Verify the `cart_item_id` belongs to the requesting user's active cart (join through `cart` on `user_id`). If not, `403`.
2. If `quantity < 1`, delete the item instead.
3. Otherwise `UPDATE cart_items SET quantity = $1 WHERE cart_item_id = $2`.

**Success response `200`:** Full cart object.

**Errors:** `400` · `401` · `403` item not in user's cart · `404` · `500`

---

#### `DELETE /cart/items/:cart_item_id`

**Logic:** Verify ownership (same join as PUT above), then `DELETE FROM cart_items WHERE cart_item_id = $1`.

**Success response `200`:** Full cart object (with item removed).

**Errors:** `401` · `403` · `404` · `500`

---

### 7.4 Order Endpoints

All order endpoints require `requireAuth`.

---

#### `POST /orders`

**Request body:**
```json
{
  "shipping_address_1": "123 Main St",
  "shipping_address_2": "",
  "shipping_city":      "San Francisco",
  "shipping_state":     "CA",
  "shipping_zip":       "94105"
}
```

**Logic (run in a single DB transaction):**

1. Fetch the active cart and its items for `req.user.user_id`. If no cart or cart is empty → `400`.
2. Compute:
   - `subtotal` = sum of `unit_price × quantity` for all items
   - `tax_rate` = `0.0798`
   - `tax_amount` = `round(subtotal × tax_rate, 2)`
   - `shipping_cost` = `0.00`
   - `total_amount` = `subtotal + tax_amount`
3. Generate `order_number`: `ORD-<timestamp_ms>` (e.g. `ORD-1718000000000`).
4. `INSERT INTO orders` with all computed fields plus shipping address and `status = 'processing'`, `created_at = NOW()`.
5. For each cart item, `INSERT INTO order_items (order_id, product_id, quantity, unit_price, line_total)`.
6. `DELETE FROM cart_items WHERE cart_id = $cart_id`.
7. `UPDATE cart SET status = 'completed', updated_at = NOW()`.
8. Return the new order.

**Success response `201`:**
```json
{
  "order_id": 15,
  "order_number": "ORD-1718000000000",
  "status": "processing",
  "subtotal": "59.98",
  "tax_rate": "0.0798",
  "tax_amount": "4.79",
  "shipping_cost": "0.00",
  "total_amount": "64.77",
  "shipping_address_1": "123 Main St",
  "shipping_city": "San Francisco",
  "shipping_state": "CA",
  "shipping_zip": "94105",
  "created_at": "2024-06-10T12:00:00.000Z",
  "items": [ { "order_item_id": 1, "product_id": "sprocket_012", "quantity": 2, "unit_price": "29.99", "line_total": "59.98" } ]
}
```

**Errors:** `400` empty cart or missing shipping fields · `401` · `500`

---

#### `GET /orders`

**SQL:**
```sql
SELECT order_id, order_number, status, subtotal, tax_amount, shipping_cost,
       total_amount, shipping_address_1, shipping_address_2,
       shipping_city, shipping_state, shipping_zip, created_at
FROM   orders
WHERE  user_id = $1
ORDER  BY created_at DESC;
```

**Success response `200`:**
```json
{ "orders": [ { "order_id": 15, "order_number": "ORD-...", ... } ] }
```

**Errors:** `401` · `500`

---

#### `GET /orders/:id`

**SQL:**
```sql
SELECT o.order_id, o.order_number, o.status,
       o.subtotal, o.tax_rate, o.tax_amount, o.shipping_cost, o.total_amount,
       o.shipping_address_1, o.shipping_address_2,
       o.shipping_city, o.shipping_state, o.shipping_zip,
       o.created_at,
       json_agg(
         json_build_object(
           'order_item_id', oi.order_item_id,
           'product_id',    oi.product_id,
           'product_name',  p.name,
           'product_image_url', p.image_url,
           'quantity',      oi.quantity,
           'unit_price',    oi.unit_price,
           'line_total',    oi.line_total
         ) ORDER BY oi.order_item_id
       ) AS items
FROM   orders o
JOIN   order_items oi ON oi.order_id = o.order_id
JOIN   products    p  ON p.product_id = oi.product_id
WHERE  o.order_id = $1 AND o.user_id = $2
GROUP  BY o.order_id;
```

Returns `403` (not `404`) if order exists but belongs to a different user.

**Success response `200`:** Full order object with `items[]`.

**Errors:** `401` · `403` order belongs to different user · `404` · `500`

## 8. `/agentSearch` Endpoint

**Method:** `POST /agentSearch`
**Auth:** None
**Content-Type:** `application/json`

### Request body

```json
{ "query": "What gear do you have for deep-space navigation?" }
```

Validate that `query` is a non-empty string. Return `400 { error: "query is required" }` otherwise.

### Step-by-step implementation

#### Step 1 — Embed the query

Use `@xenova/transformers` with the `Xenova/all-MiniLM-L6-v2` model (384 dimensions). The pipeline must be initialised once at module load time (not per request) because model loading is slow.

```javascript
import { pipeline } from '@xenova/transformers';

// Module-level singleton — initialised on first call or at startup
let embedder = null;
async function getEmbedder() {
  if (!embedder) {
    embedder = await pipeline('feature-extraction', 'Xenova/all-MiniLM-L6-v2');
  }
  return embedder;
}

// In the route handler:
const embed = await getEmbedder();
const output = await embed(query, { pooling: 'mean', normalize: true });
const queryEmbedding = Array.from(output.data);   // plain JS number[]
```

#### Step 2 — Query OpenSearch (k-NN top 4)

```javascript
import { Client } from '@opensearch-project/opensearch';

const opensearchClient = new Client({
  node: `http://${process.env.OPENSEARCH_HOST}:${process.env.OPENSEARCH_PORT}`,
});

const result = await opensearchClient.search({
  index: process.env.OPENSEARCH_INDEX,
  body: {
    size: 4,
    query: {
      knn: {
        embedding: { vector: queryEmbedding, k: 4 },
      },
    },
  },
});

const products = result.body.hits.hits.map(h => ({
  product_id:          h._source.product_id,
  product_name:        h._source.product_name,
  product_description: h._source.product_description,
  product_image_url:   h._source.product_image_url,
}));
```

If OpenSearch returns 0 hits, return `200 { agent_response: "No products found for your query.", products: [] }` without calling the agent.

#### Step 3 — Call watsonx Orchestrate (`agent-integrate` skill pattern)

**Obtain a bearer token** using the IBM Cloud IAM token endpoint:

```javascript
const iamResp = await axios.post(
  'https://iam.cloud.ibm.com/identity/token',
  new URLSearchParams({
    grant_type: 'urn:ibm:params:oauth:grant-type:apikey',
    apikey: process.env.WO_API_KEY,
  }),
  { headers: { 'Content-Type': 'application/x-www-form-urlencoded' } }
);
const bearerToken = iamResp.data.access_token;
```

**Send the message to the agent:**

```javascript
const agentPayload = {
  input: `User query: ${query}\n\nProduct results:\n${JSON.stringify(products, null, 2)}`,
};

const woResp = await axios.post(
  `${process.env.WO_INSTANCE_URL}/v1/agents/${process.env.WO_AGENT_ID}/chat`,
  agentPayload,
  {
    headers: {
      Authorization: `Bearer ${bearerToken}`,
      'Content-Type': 'application/json',
    },
  }
);

const agent_response = woResp.data?.output ?? woResp.data?.response ?? '';
```

> **`WO_AGENT_ID` and `WO_ENVIRONMENT_ID`** are populated in `.env` after the `product_search` agent is deployed (Spec 5). The backend reads them directly from `process.env` — no defaults or fallbacks. If `WO_AGENT_ID` is not set, log a warning and return `503 { error: "Agent not configured" }`.

#### Step 4 — Return response

```json
{
  "agent_response": "These products are perfect for deep-space navigation...",
  "products": [
    {
      "product_id": "sprocket_007",
      "product_name": "Stellar Compass Pro",
      "product_description": "...",
      "product_image_url": "https://..."
    }
  ]
}
```

**Error codes:** `400` missing query · `500` embedding or OpenSearch failure · `503` WO agent not configured or WO API error

## 10. CORS Configuration

```javascript
import cors from 'cors';

const allowedOrigins = [
  'http://localhost:5173',   // Vite dev server
  'http://localhost:3000',   // Alternative local port
];

app.use(cors({
  origin: (origin, callback) => {
    // Allow requests with no origin (curl, Postman, same-origin container calls)
    if (!origin || allowedOrigins.includes(origin)) {
      callback(null, true);
    } else {
      // Wildcard fallback for container-to-container scenarios (no browser Origin header)
      callback(null, true);
    }
  },
  credentials: true,
}));
```

> For stricter production environments, restrict the wildcard fallback by checking against a `CORS_ORIGIN` env var if needed.
