BUILT FOR YOUR APPLICATIONS
REST and ACP APIs.

    
Send your service token as Authorization: Bearer TOKEN. Requests and responses are JSON; live events use SSE.

    
Developer guide and Python samples ↗

    
REST threads API

    

      
POST /api/v1/threads
Create a conversation with an optional title.

      
GET /api/v1/threads
List and search your threads. Supports pagination.

      
PATCH /api/v1/threads/{id}
Rename, archive, or restore a thread.

      
DELETE /api/v1/threads/{id}
Delete the conversation from the wrapper. Run records and workspace files are retained.

      
POST /api/v1/threads/{id}/messages
Send {"content":"Your task"}. Returns a run immediately.

      
GET /api/v1/threads/{id}/messages
Read saved messages and responses.

      
GET /api/v1/threads/{id}/files
List workspace files. Use ?path=folder for a directory.

      
GET /api/v1/threads/{id}/files/download?path=tetris.html
Download a file as an attachment (up to 25 MiB). Requires the same service token.

      
GET /api/v1/runs/{id}/events
Stream live events. Reconnect with Last-Event-ID.

      
GET /api/v1/runs/{id}
Run status, output and optional usage statistics. Assistant messages also include usage when available.

      
POST /api/v1/runs/{id}/cancel
Stop a queued or executing run.

    

    
Use an Idempotency-Key when sending a message to safely retry the same request. One run can be active per thread.

    REST OpenAPI specification ↗
    
ACP 0.2.0 API

    
ACP uses root-level routes on this same service and the same service token. It supports text runs and session continuation. Use ACP from a server or CLI; browser Origin requests are rejected.

    

      
GET /agents · GET /agents/headlessbob
Discover the Bob agent and its capabilities.

      
POST /runs
Create a run with mode sync, async or stream. Pass session_id to continue a completed task.

      
GET /runs/{run_id}
Read status, output and usage.

      
GET /runs/{run_id}/events
Read persisted events as JSON.

      
POST /runs/{run_id}/cancel
Cancel a queued or running task.

      
GET /session/{session_id}
Read session run history.

Threads and messages survive service restarts. A failed or cancelled execution may require a fresh thread. Attachments and thread branching are not supported yet.
